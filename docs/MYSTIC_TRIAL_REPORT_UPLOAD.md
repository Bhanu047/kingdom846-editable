# Mystic Trials battle-report upload guidance

Mystic Trials now includes a Battle Report Import guide using the user-provided Troop Power Comparison switch reference. Players are instructed to switch the report from troop percentages to actual troop counts before taking and uploading the screenshot.

Required screenshot state:
- Open Battle Details → Troop Power Comparison.
- Tap the switch icon in the top-right of the comparison panel.
- Confirm the troop composition displays actual Infantry, Cavalry and Archer numbers, not values such as 50.00%, 15.00%, 35.00%.
- Upload the battle report from the Mystic Trials panel.

The guide button opens the existing Battle Lab screenshot-import flow. The reference image is stored as `public/assets/mystic-trial-troop-toggle.webp`.
